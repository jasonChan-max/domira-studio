# Complete interactive single-file demo

`public/downloads/domira.html` is a standalone HTML/CSS/JavaScript file. Save it and open it in a modern browser. No packages, API keys or build step are required. Reference photographs load from Unsplash, so images require an Internet connection; all local interaction remains in the file.

It includes a three-scene fading carousel with pause controls and reduced-motion support; full-height room sections; accessible native dialogs with styles, furniture combinations and itemized HKD allowances; text-list downloads; and a matching local floor-plan workbench with draggable/rotatable furniture, color themes, browser storage and JSON export.

The local workbench is a demonstration with boundary clamping. It does not call AI or provide collision/doorway/accessibility validation. The formal Domira workbench remains linked separately. Prices are category allowances, not merchant quotes. Reference photographs do not claim to represent generated projects or correspond to the listed furniture.

Validation: inline JavaScript syntax; DOM checks for room detail navigation, style/variant selection, six-item budget total, workbench opening, local project save, close/overflow cleanup and carousel controls; complete repository tests and build checks.
